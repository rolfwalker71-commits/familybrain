# Android TWA project (generated locally)

Do **not** commit Bubblewrap output or keystores here.

1. Follow [docs/android-twa.md](../docs/android-twa.md)
2. Run `bubblewrap init` in this folder (or a sibling `android-build/`)
3. Copy snippets from [`snippets/`](snippets/) into the generated project for widgets + notification delegation

Signing keys and `*.jks` / `*.keystore` stay on your machine (gitignored).
